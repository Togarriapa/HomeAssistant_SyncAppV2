1

Connect a private repository

Create an empty private GitHub repository. Set repository to owner/name in this app’s Configuration tab.

Set github_metadata_token to a fine-grained token restricted to this repository with read-only Metadata permission. It checks privacy and repository identity. All Git transfers use your SSH deploy key.

2

Set up the deploy key

Generate a key, then add its public key in Repo B → Settings → Deploy keys. Select “Allow write access”.

Refresh prepares a replacement. The current key stays active until the replacement passes its test and you activate it. The private key stays inside SyncApp.

3

Initialize Repo B

Make the initial push of your running configuration and create main, candidate, database, runtime and logs.

Automatic synchronization stays blocked until initialization succeeds. Repo B must be empty and private; Home Assistant must be healthy.
